# Map CONTEXT — how to walk this map

This is an ICM **System Map**: a record library of nouns (objects), a shelf of verbs (processes), and a change-impact index (effects). The subject tree (`~/Projects/Katiba/AFFiNE`) stays the source of truth; this map only cites it.

## Walking rules

1. Enter through `map/CLAUDE.md`. Answer "where am I / where do I go" from its tables without opening a card.
2. For any noun, find it in `objects/_index.md`, open its card, follow `See` links to source — never to another essay.
3. Before planning a change, read `effects/CONTEXT.md` and open every card it lists for your target.
4. Token budget: catalog + one hub CONTEXT + one card should land in roughly 2k–8k tokens. If a card grows past that, split or move detail to the source repo.

## Universes

Everything mapped here was classified against the working tree at commit `a8eef5396` (canary):

- **live** — in force; implement and cite against these. All cards below are `live` unless marked otherwise.
- **leftover** — present but not the main path. Example: `packages/frontend/native/sqlite_v1` (v1 local database, superseded by the current nbstore schema crate).
- **ghost** — named or filed but not wired. None identified yet; docs warn themselves that `docs/*.md` "is not guaranteed to be up-to-date" (`docs/developing-server.md:5`), so treat prose docs as possibly stale, never as spec.

## Status field

- `verified` — card claims were checked against source on the dated commit. Requires date + commit + citations.
- `stale` — source moved on; re-verify before trusting.
- `stub` — placeholder line only, no body yet.

## Maintenance

- Re-verify load-bearing claims (especially _If you change this_) after major refactors; update `verified:` with the new date + commit.
- `AGENTS.md` and `routing.md` are byte-identical twins of `CLAUDE.md`, generated by copy — never hand-edit them separately.
- One home per fact: a fact lives in its card (or in source); indexes only point at it.
